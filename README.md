### 🤖 Inteligência Artificial

> **IA = conjunto de metodologias e técnicas utilizadas para desenvolver sistemas com comportamento inteligente.**

### 🏥 Aplicações da IA na Saúde

O arquivo `mapaMentalTIAS.png` apresenta algumas áreas em que a Inteligência Artificial pode auxiliar na Saúde:

- **Diagnóstico**
  - Medicina;
  - Odontologia;
  - Reconhecimento de padrões.

- **Monitoramento**
  - Enfermagem;
  - Sensoriamento.

- **Reconhecimento de padrões**
  - Farmácia.

- **Sistemas autônomos e gadgets**
  - Fisioterapia.

### 🎯 Problemas ou Desafios para Técnicas de IA

#### 1. Diagnóstico

O diagnóstico pode utilizar técnicas de **reconhecimento de padrões**.

```text
Amostras
   ↓
Treinamento
   ↓
Reconhecimento de padrões
   ↓
Resultado
```

Para isso, podem ser utilizadas:

- Amostras;
- Dados de treinamento;
- Algoritmos de reconhecimento de padrões.

#### 2. Monitoramento ou Sensoriamento

Os sistemas podem trabalhar com diferentes tipos de dados:

- 🖼️ Imagens;
- 🎥 Vídeos;
- 🔊 Áudios;
- 📝 Textos.

### 🧩 Entendimento

#### Recomendar

A recomendação pode ser baseada no histórico do usuário.

```text
Histórico do usuário
        ↓
Análise dos dados
        ↓
Recomendação
```

#### Apoiar a decisão

O apoio à decisão pode utilizar dados concretos coletados ao longo de vários anos.

```text
Dados históricos
       ↓
Análise
       ↓
Identificação de padrões
       ↓
Apoio à decisão
```

### ⛏️ KDD e Mineração de Dados

**KDD — Knowledge Discovery in Databases**

```text
KDD
 ↓
Mineração de Dados
 ↓
Reconhecimento de Padrões
 ↓
Predição e Previsão
```

### 🤖 Modelos Treinados

Os modelos são treinados utilizando amostras e conjuntos de dados.

```text
Amostras
   ↓
Conjunto de dados
   ↓
Treinamento
   ↓
Modelo
```

### 📥 Entrada

As entradas podem ser representadas por:

```text
X[n]
```

ou:

```text
features[n]
```

Onde `n` representa:

- Atributos;
- Características;
- Propriedades;
- Variáveis.

### 📤 Saída Esperada

A saída pode ser representada por:

```text
Y
```

Também pode ser chamada de:

- `target`;
- Resultado esperado;
- Variável alvo.

### 🔢 Resultado Binário

Um modelo pode produzir uma saída binária:

```text
0 → Não
1 → Sim
```

Representação geral:

```text
X → Modelo → Y
```

### 🎯 Predição

A predição utiliza modelos treinados, geralmente baseados em modelos matemáticos.

Pode envolver:

- Classificação;
- Categorização;
- Etiquetagem;
- Rotulação.

```text
Dados
  ↓
Modelo treinado
  ↓
Classificação
```

### 📈 Previsão

A previsão busca projetar ou estimar valores futuros com base em dados anteriores.

```text
Dados históricos
        ↓
Reconhecimento de padrões
        ↓
Modelo
        ↓
Previsão
```
